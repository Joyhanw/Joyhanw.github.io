    02 核心痛点与优先级

    先围绕客户真实痛点排优先级，再决定业务中心、AI员工和Demo范围。

    P0 最致命

    术后康复闭环断裂

    患者出院后缺少持续管理，随访率低、康复动作不规范、异常发现晚，直接影响疗效、满意度与口碑。

    对应中心FRC 康复管理中心核心AI康复管家 / 随访专员 / 风险预警员
    P1 高价值

    医生文书与临床效率低

    病历、报告、术前资料整理占用医生大量时间，影响接诊效率和医疗服务体验。

    对应中心CSC 临床支持中心核心AI病历文书师 / 影像诊断师 / 手术规划师
    P1 高价值

    患者咨询与预约流失

    患者不知道挂什么科，线上咨询回复慢、夜间无人承接，导致潜在患者流失。

    对应中心STH 智能分诊中台核心AI智能分诊师 / 预约调度官
    P2 后续深化

    医保控费与质控压力

    DRG/DIP、费用审核、病案归档、病历质控等对医院合规和经营结果影响大。

    对应中心AOC 行政运营中心 / CSC 临床支持中心核心AI医保结算员 / 病案管理员 / 质控监察员
    P1 私立医院重点

    品牌增长与运营获客

    私立医院更关注咨询承接、线索转化和口碑增长，短视频、直播、本地生活平台需要持续运营。

    对应中心BGC 品牌增长中心核心AI品牌专家 / 直播运营官 / 本地增长官

    1. 患者办理出院，系统自动开通康复服务
    2. 患者端收到分阶段康复计划与训练提醒

    5. 患者反馈疼痛、肿胀、发热、渗液等异常

    09 科室价值与AI应用场景

    门诊

    分诊 + 预约 + 病历
    患者症状咨询 → AI导诊推荐科室/医生 → 预约挂号 → 医生接诊前查看AI摘要 → 接诊后AI生成门诊病历草稿。

    住院病区

    病程 + 出院小结
    查房语音/医嘱/检查记录 → AI整理病程记录、出院小结草稿 → 医生审核后进入EMR或复制使用。

    康复科

    术后闭环
    出院信息/术式 → AI生成康复计划 → 康复师审核 → 患者打卡/随访 → 异常预警 → 康复师处理。

    影像科

    辅助判读
    PACS影像 → AI识别骨折、退变、椎间盘等异常 → 标注重点区域 → 影像医生审核报告。

    检验/药房

    异常提醒 + 用药审核
    LIS结果/处方数据 → AI标记异常、危急值提醒、处方配伍和剂量审核 → 医护药师确认。

    医务科/质控

    质控闭环
    运行病历、手术、院感数据 → AI自动巡检 → 问题工单 → 科室整改 → 质控报告。

    医保办/病案室

    控费 + 编码
    拟出院患者 → AI进行DRG预分组、费用风险审核、病案首页编码建议 → 降低拒付扣款风险。

    市场运营/客服

    私立医院获客重点
    抖音/视频号/小红书/美团咨询 → AI自动回复、分诊、留资打标 → 高意向线索转人工 → 预约转化统计。

    供应链/后勤

    耗材 + 工单
    高值耗材库存、手术排班、报修工单 → AI效期/库存/能耗预警 → 人工确认处理。

    院办/院领导

    驾驶舱
    汇总诊疗、康复、运营、医保、AI调用数据 → 展示效率提升、风险处理、患者转化和经营指标。

    10 重点业务场景闭环

    场景一｜AI病历生成

    医生说一句话，生成结构化病历草稿

    医生在业务系统打开患者详情，点击AI助手
    医生口述/输入：患者膝关节疼痛半年，活动后加重...
    AI提取主诉、现病史、查体、初步处理建议，生成病历草稿
    医生审核修改，保存到EMR；无法写回时先复制使用
    场景二｜术后康复闭环

    出院后不失联，异常能预警

    患者办理出院，系统获取手术类型和出院医嘱
    AI康复管家生成计划，康复师审核发布
    患者打卡/AI随访，反馈疼痛、肿胀、发热
    医生/康复师收到风险待办，处理后进入驾驶舱统计
    场景三｜智能导诊预约

    患者不知道挂什么科，AI帮忙分流转化

    患者在小程序/网页/公众号输入“腿疼、膝盖痛”
    AI多轮追问部位、时长、诱因、伴随症状
    推荐关节科/运动医学科/脊柱科与医生号源
    患者确认预约；医生端查看AI分诊摘要
    场景四｜公域获客转化

    私立医院重点：咨询不丢、线索可追

    抖音/美团/视频号/小红书咨询进入统一入口
    AI秒级回复常见问题，识别高意向、初步分诊
    生成留资表单/预约入口，转人工客服跟进
    运营端查看线索标签、渠道转化、预约结果与复盘建议
