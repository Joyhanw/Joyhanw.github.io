    02 核心痛点与优先级

    先围绕客户真实痛点排优先级，再决定业务中心、AI员工和Demo范围。

    P0 最致命

    术后康复闭环断裂

    患者出院后缺少持续管理，随访率低、康复动作不规范、异常发现晚，直接影响疗效、满意度与口碑。

    对应中心FRC 康复管理中心核心AI康复管家 / 随访专员 / 风险预警员
    P1 高价值

    医生文书与临床效率低

    病历、报告、术前资料整理占用医生大量时间，影响接诊效率和医疗服务体验。

    对应中心CSC 临床支持中心核心AI病历文书师 / 影像诊断师 / 手术规划师
    P1 高价值

    患者咨询与预约流失

    患者不知道挂什么科，线上咨询回复慢、夜间无人承接，导致潜在患者流失。

    对应中心STH 智能分诊中台核心AI智能分诊师 / 预约调度官
    P2 后续深化

    医保控费与质控压力

    DRG/DIP、费用审核、病案归档、病历质控等对医院合规和经营结果影响大。

    对应中心AOC 行政运营中心 / CSC 临床支持中心核心AI医保结算员 / 病案管理员 / 质控监察员
    P1 私立医院重点

    品牌增长与运营获客

    私立医院更关注咨询承接、线索转化和口碑增长，短视频、直播、本地生活平台需要持续运营。

    对应中心BGC 品牌增长中心核心AI品牌专家 / 直播运营官 / 本地增长官

    • 门诊病历、病程、出院小结耗时
    • 影像判读、术前规划依赖经验

    医生口述/患者预问诊→AI提取结构化信息→生成病历/摘要→医生审核

    • 异常信息需要人工判断分级

    节点触发→AI宣教/随访→患者反馈→异常转待办

    09 科室价值与AI应用场景

    门诊

    分诊 + 预约 + 病历
    患者症状咨询 → AI导诊推荐科室/医生 → 预约挂号 → 医生接诊前查看AI摘要 → 接诊后AI生成门诊病历草稿。

    住院病区

    病程 + 出院小结
    查房语音/医嘱/检查记录 → AI整理病程记录、出院小结草稿 → 医生审核后进入EMR或复制使用。

    康复科

    术后闭环
    出院信息/术式 → AI生成康复计划 → 康复师审核 → 患者打卡/随访 → 异常预警 → 康复师处理。

    影像科

    辅助判读
    PACS影像 → AI识别骨折、退变、椎间盘等异常 → 标注重点区域 → 影像医生审核报告。

    检验/药房

    异常提醒 + 用药审核
    LIS结果/处方数据 → AI标记异常、危急值提醒、处方配伍和剂量审核 → 医护药师确认。

    医务科/质控

    质控闭环
    运行病历、手术、院感数据 → AI自动巡检 → 问题工单 → 科室整改 → 质控报告。

    医保办/病案室

    控费 + 编码
    拟出院患者 → AI进行DRG预分组、费用风险审核、病案首页编码建议 → 降低拒付扣款风险。

    市场运营/客服

    私立医院获客重点
    抖音/视频号/小红书/美团咨询 → AI自动回复、分诊、留资打标 → 高意向线索转人工 → 预约转化统计。

    供应链/后勤

    耗材 + 工单
    高值耗材库存、手术排班、报修工单 → AI效期/库存/能耗预警 → 人工确认处理。

    院办/院领导

    驾驶舱
    汇总诊疗、康复、运营、医保、AI调用数据 → 展示效率提升、风险处理、患者转化和经营指标。

    10 一期核心业务闭环

    本页只展示一期需要重点支持的四个业务场景，保证与功能清单、Demo和后续报价范围一致。

    S01｜智能导诊预约闭环

    患者不知道挂什么科，AI完成分诊与预约转化

    患者在公众号/小程序/H5输入“膝盖疼、腰疼、运动损伤”
    AI智能分诊师多轮追问部位、时长、诱因和伴随症状
    推荐科室、医生、检查建议，并由预约调度官引导预约
    医院端接收预约信息、AI导诊摘要和待跟进线索
    S02｜智能康复管理闭环

    出院后不失联，康复执行可追踪、异常可预警

    患者出院后进入康复管理流程，生成康复档案
    AI康复管家生成计划，康复训练师推送训练任务
    患者打卡/AI随访，反馈疼痛、肿胀、发热等情况
    AI风险预警员生成待办，医生/护士/康复师处理闭环
    S03｜AI品牌增长闭环

    私立医院重点：咨询不丢、复诊和转介绍可运营

    抖音/视频号/小红书/公众号咨询进入统一入口
    AI品牌专家秒级回复，识别高意向患者并引导留资/预约
    治疗/康复后推送满意度、复查提醒和转介绍触达
    运营端查看线索标签、渠道转化、复诊率和转介绍数据
    S04｜患者健康档案闭环

    患者数据统一沉淀，支撑导诊、康复、运营和驾驶舱

    导诊、预约、就诊、检查、康复、随访数据持续产生
    AI健康档案管理员汇聚资料，生成档案摘要与标签画像
    医生查看患者360档案，运营查看患者分层和风险标签
    院领导查看患者总量、档案完整率、风险画像和服务效果

    一、客户现状确认

    系统现状：确认HIS、EMR、PACS、预约、排班、CRM、短信、外呼、公众号/小程序是否已有。
    角色现状：确认患者服务人员实际是客服、导医、医助还是护士承担。
    业务现状：确认导诊、预约、康复、随访、患者运营、健康档案现在怎么跑。

    二、一期Demo准备

    导诊预约：患者症状咨询 → AI分诊 → 推荐医生 → 预约/登记 → 医院端查看。
    康复随访：出院 → 康复计划 → 打卡/随访 → 异常预警 → 医护处理。
    品牌增长：公域咨询 → AI承接 → 留资/预约 → 运营端转化统计。
    健康档案：患者数据沉淀 → AI摘要 → 标签画像 → 支撑康复与运营。

    三、客户可能追问与应答准备

    客户可能问建议应答口径需要准备的材料
    没有患者端怎么办？可以通过独立H5、短信链接、公众号消息或AI电话外呼先跑通，后续再接入正式患者端。多通道触达方案
    没有挂号/排班接口怎么办？先用预约登记表和后台维护排班兜底，接口开放后再做系统直连。标准流程+兜底流程图
    康复风险谁处理？AI只做识别和分级提醒，医生、护士、康复师负责确认和处理，形成闭环记录。预警分级规则
    增长运营是不是一期必须做？对私立医院价值很高，但是否放P0需结合客户运营团队和获客目标确认。S03价值说明、运营功能清单
    病历、影像为什么不放一期？属于深度临床支持能力，对EMR/PACS依赖强，可作为二期重点扩展。二期规划与接口依赖说明
