从公开资料看，大金已在多个业务环节形成数字化与 AI 实践，后续可进一步关注能力深化与跨环节协同。
对比行业：深化什么，参考什么
A · 现有优势深化
设备智能运维Daikin Care + AirNet + DK-CONNECT + AI节能

可深化至：设备健康管理、预测性维护、自动服务触发。

现场服务远程支援DX + THINKLET + SE能力

可深化至：AI维修诊断、AI现场作业助手、知识自动沉淀。

安装品质安装规范 + App可视 + AI辅助

可深化至：AI安装质量检查、整改闭环、服务商质量评价。

B · 行业参考方向
AI智能选型（参考美的、海尔）

已有 BIM + 能耗分析 + 科学提案 → 需求输入 → 自动选型 → 方案比较 → 报价 / 初步方案。

AI供应协同（参考海尔）

订单预测 → 物料计划 → 供应商协同 → 异常预警；与课题 02 衔接。

AI生产质量（参考海尔、格力）

工序动作识别 → 在线质检 → 自动拦截 → 质量追溯。

AI柔性排产（参考海尔、美的）

多规格、小批量、定制订单场景的适用性评估。
